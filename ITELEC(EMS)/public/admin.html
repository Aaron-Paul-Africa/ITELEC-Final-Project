Monthly attendance exports

EMS saves the previous month's Excel file after midnight on the first day of each month, using Manila time.

The EMS server must be running at month-end. If it is offline, the file is generated when the server starts again.

Access roles

Use roles to guide access to employee management features.

Role Intended access
Super Administrator Has the same management access as HR Personnel, including user account creation, employee records, attendance, and payroll.
Administrator / HR Personnel Has the same management access as Super Administrator, including user account creation, employee records, attendance, and payroll.
Employee Views the employee directory, their own attendance and payroll, and can update their own username or password. Cannot make management edits or change their role.
